# KasBan_ToDo

A modern Kanban & To-Do web application built with React, Vite, TypeScript, Tailwind CSS, and TanStack Router.

## 🚀 Tech Stack

- **Framework**: React 19 + Vite
- **Language**: TypeScript
- **Styling**: Tailwind CSS v4
- **Routing**: TanStack React Router
- **Form Management & Validation**: React Hook Form + Zod
- **State Management**: Zustand
- **Icons**: Lucide React

## 📦 Getting Started

### Prerequisites

Make sure you have Node.js / Bun installed.

### Installation

```bash
npm install
# or
bun install
```

### Running Locally

```bash
npm run dev
# or
bun dev
```

### Building for Production

```bash
npm run build
```
